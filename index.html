The Nexus concept

Developed by Charlles Pereira Costa from an IT support background, Nexus explores recurring support agreements. This academic project examines technical delivery in a small test environment before taking on real customers.

Cloud operations

Planned Microsoft 365 and Entra ID test environment with approximately ten fictional users and a small number of virtual machines.

Repeatable automation

Planned PowerShell scripts for user and group administration, supported by documentation and test evidence.

Structured support

A ticket template, support workflow, onboarding checklist and draft knowledge articles, evaluated with ten fictional cases.

Pilot scope and deliverables

Deliverables

  • Updated service description and draft service levels
  • Documented test environment
  • PowerShell scripts and README
  • Support process and case records
  • Final report and continuation recommendation

Outside this project

  • Real clients and personal information
  • Company registration and sales
  • Final pricing and contracts
  • Production ticketing and on-call support
